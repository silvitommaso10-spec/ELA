Usage: bw config [options] <setting> [value]

Configure CLI settings.

Options:
  --web-vault <url>      Provides a custom web vault URL that differs from the
                         base URL.
  --api <url>            Provides a custom API URL that differs from the base
                         URL.
  --identity <url>       Provides a custom identity URL that differs from the
                         base URL.
  --icons <url>          Provides a custom icons service URL that differs from
                         the base URL.
  --notifications <url>  Provides a custom notifications URL that differs from
                         the base URL.
  --events <url>         Provides a custom events URL that differs from the base
                         URL.
  --key-connector <url>  Provides the URL for your Key Connector server.
  -h, --help             display help for command

  Settings:

    server - On-premises hosted installation URL.

  Examples:

    bw config server
    bw config server https://bw.company.com
    bw config server bitwarden.com
    bw config server --api http://localhost:4000 --identity http://localhost:33656
